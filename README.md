# 中国县域统计年鉴 · 县市卷 Excel 自动下载

一个 200 行左右的脚本，在你**本来就有中国知网下载权限**的前提下，把《中国县域统计年鉴》某一卷（县市卷）各年度的统计表格 Excel 一次性批量下载到本地。

平台上一本县市卷共有 **54 张**可下载的 Excel 统计表（52 张分省社会经济主要指标表 + 2 张按地方一般公共预算收入分组的资料表），脚本按“年份 → 章 → 条目”逐层遍历，全部拉齐，并支持中断后重跑续传。

> 本仓库只包含脚本，不包含任何年鉴数据文件。数据版权归中国知网及原出版方所有。

---

## 设计思路

这套代码解决的是一个很具体的矛盾：知网的统计表是**逐条点开、逐张下载**的，一本年鉴 54 张表、两年就是 108 次点击；而平台又有反爬与拼图验证，纯 headless 的自动脚本很难长期稳定跑通。所以设计上刻意把“机器能做的”和“只能人做的”切开。

1. **机器负责“找”和“下”**：所有目录信息（年度列表、卷别、章节、条目、文件代码）都走平台自身的 JSON 接口获取，不解析页面、不模拟点击；真正下载时拿到的是接口返回的签名直链，直接 GET 二进制流，按文件头判断 `.xls` / `.xlsx` 后落盘。
2. **人负责“过验证”**：脚本用**可见窗口**的真实 Chrome 启动，遇到拼图验证时停在那一步、把窗口留给人工完成，完成后重跑即可——因为脚本是幂等的，已下好的表会按文件名跳过，不会重复下载。
3. **用豆包（Doubao）+ Agent 模式来写和跑**：这份代码不是手敲的，而是由豆包 AI 助手在拿到接口结构后自行编写、执行、读日志、修 bug、校验文件头，人只负责两件事——提供访问环境的网络条件，以及在被拦时手动过拼图。

换句话说，它是“**AI 写代码 + AI 跑批 + 人工兜底验证**”的一个最小样板。

## 工作原理

接口根地址：`https://data.cnki.net/api/csyd`，四步链路如下。

| 步骤 | 接口 | 作用 |
| --- | --- | --- |
| 1 | `POST /StatisticalData/GetYbYearAndCode` | 传任一已知卷册 `code`（如 `N2024030156`），取回“全部年度 + 卷别”清单，形如 `2024(县市卷)`、`2025(乡镇卷)` |
| 2 | `POST /StatisticalData/GetContentByCode` | 传卷册 code 与拼音码 `YZGCA`，取回该卷的章节列表和明文 code |
| 3 | `POST /StatisticalData/GetEntResByCodeAndParNode` | 按章节 `parNode` 分页（100 条/页）取条目，筛出 `czexcel == 1` 的 Excel 条目 |
| 4 | `POST /StatisticalData/PdfAndCajDownload` | 用条目 `fileCode` 换取一次性下载直链，再 GET 到内存 |

落盘时按 `题名-页码.xls` 命名（页码取目录接口的 `ysym` 字段），例如：

```
2025/北京市-3.xls
2025/2024年县(市)社会经济主要指标 四川省-277-303.xls
```

文件名会做一轮清理：去掉换行、把 `\ / : * ? " < > |` 替换为下划线、压缩多余空白，避免 Windows 下保存失败。

**幂等与续传**：下载前先看输出目录里是否已有同名文件，有就跳过。所以脚本可以随时 Ctrl+C、随时重跑，跑第二遍只会补缺的那些。

**节奏控制**：每张表间隔 3 秒、章节末 0.5 秒、条目翻页 1 秒，单年 54 张表大约 3～5 分钟，属于温和频率。

## 环境要求

- **权限**：校园网 / 机构 IP / 已订阅的知网账号。脚本本身不绕过任何付费墙或登录，权限不足时会明确报“未登录”。
- **Python 3.8+**，依赖只有一个：
  ```bash
  pip install playwright
  ```
- **Chrome**（脚本用 `channel='chrome'` 调用系统已安装的 Chrome，不需要额外 `playwright install`；若想用 Playwright 自带浏览器，把 `channel='chrome'` 删掉再执行 `playwright install chromium`）。
- 必须能打开**可见窗口**（不能是无头服务器），因为拼图验证需要人工完成。

## 使用

```bash
# 下载配置区里的 TARGET_YEARS（默认 2024、2025）
python 下载县域年鉴县市卷.py

# 只下某一年
python 下载县域年鉴县市卷.py 2025
```

输出目录就是脚本所在目录下的 `<年份>`，已有同名文件自动跳过。

运行时会打印平台收录的全部卷册、每章的条目数、可下载表总数，以及逐条的 `(序号/总数) 题名-页码 [fileCode]`。结尾汇总成功 / 跳过 / 失败三个计数。

## 配置区

改这几行就能换目标：

| 变量 | 含义 | 备注 |
| --- | --- | --- |
| `ROOT_CODE` | 任一已知卷册代码 | 只用来拉“年度 + 卷别”清单，随便哪一卷都行 |
| `PINYIN_CODE` | 目录接口需要的拼音码 | 《中国县域统计年鉴》为 `YZGCA`，其他年鉴不同 |
| `TARGET_YEARS` | 要下的年份列表 | 命令行参数优先于它 |
| `INTERVAL` | 每张表间隔秒数 | 遇限流就调大 |

平台收录情况（脚本运行时会打印）：2013 年起分“县市卷 / 乡镇卷”两种，2000–2012 年为单卷。把 `TARGET_YEARS` 换成 `['2000', '2001', ...]` 即可批量补齐历史年份。

> 注意：脚本只处理 `czexcel == 1` 的条目，即平台提供 Excel 版的统计表；PDF 版不在范围内。封面、编委会、编者说明、指标解释等章节本来就没有 Excel，条目数为 0 属正常。

## 关于拼图验证

这是本方案唯一无法自动化的环节，也是设计上刻意留给人的部分。

- 下载请求返回的不是 Excel 而是 HTML，且 URL 跳到了 `/bar/verify/`，脚本会打印：`需要拼图验证：请在浏览器窗口完成验证后重跑脚本`。
- 此时程序**不会退出**，浏览器窗口保持打开，你在窗口里把拼图拖完即可；然后关掉窗口（或直接 Ctrl+C），重跑脚本，已下好的表会自动跳过。
- 同理，若报 `未登录：请在浏览器窗口登录知网后重跑脚本`，在窗口里登录一次再重跑。

因为每次都启动**干净的临时浏览器上下文**（不落配置目录），所以每次运行都要重新过验证；这是用“稳定性”换“不留痕”的取舍。若你更在意少过几次验证，可以把 `new_context` 改成 `launch_persistent_context` 并指定一个本地目录。

## 常见问题

**Q：报 `获取下载链接失败`？**
A：通常是没有权限或会话失效。浏览器里手动打开一条统计表确认能下，再重跑。

**Q：某几条一直失败，其他都成功？**
A：先跑一遍，把失败的单独拎出来重跑（脚本按文件名跳过，只会补缺）。若仍失败，多为该条目的下载直链有独立校验，需在窗口里手动点一次。

**Q：下载下来的文件打不开？**
A：脚本按文件头（`D0CF11E0` → `.xls`，`PK` → `.xlsx`）判断真实类型，正常不会是 HTML 伪装。若出现打不开的，检查是否被验证页顶替（文件很小、几十 KB 以下）。

**Q：能不能跑在服务器上？**
A：不行。可见窗口是设计前提，无头环境下无法人工过验证。

## 开发方式

代码由**豆包（Doubao）Agent 模式**在真实会话中生成并执行：先由接口响应反推目录结构，再落成四步请求链路，跑批过程中读日志、处理文件头校验、确认 108 个文件全部为合法 Excel 格式。人类参与的部分只有网络环境、权限确认与拼图验证。

如果你也想把类似的“网页手工点点点”变成可复跑的小工具，这个仓库就是一个可复制的骨架：**接口取数 → 直链落盘 → 文件名判重续传 → 关键验证交给人**。
